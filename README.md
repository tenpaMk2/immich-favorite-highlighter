# Immich Favorite Highlighter

💛 Immich のタイムラインやアルバムで、お気に入り画像のサムネイルを強調する Chrome 拡張機能です。Brave でも動作します。

Immich 標準の fav 表示は、左下の縁なし白いハートだけです。明るい写真の上ではほぼ見えません。この拡張は次の 2 つを足します。

- お気に入りサムネ全体に、暗い縁つきの枠線
- 左下ハート自体に黒い縁とドロップシャドウ

Immich のサムネイル DOM（`data-asset` と `data-icon-favorite`）を CSS で装飾するだけなので、ページのリロードや API フックは不要です。

## インストール

1. Chrome で `chrome://extensions` を開く（Brave なら `brave://extensions`）
2. 「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

## 初回設定

1. ツールバーの拡張機能アイコン → 「オプションを開く」
2. Immich の URL を入力する（例: `https://photos.example.com`）
3. 枠線の色と太さを好みで調整する
4. 「保存」を押し、ホスト許可を承認する
5. 開いている Immich のタブを再読み込みする

## 使い方

1. Immich にログインし、タイムラインやアルバムを開く
2. お気に入りのサムネに枠線が付き、左下のハートに縁が付く
3. 強調を止めたいときは、ポップアップの「お気に入りを強調する」を OFF にする

## 動作条件

- 拡張機能が ON であること
- サムネイルに Immich の fav アイコンが出ていること（共有リンクでは公式側もハートを出さない）

拡大ビューアのツールバーは対象外です。タイムライン、アルバム、検索など、サムネイル一覧が対象です。

## 注意

- Immich のサムネイル DOM が変わった場合は、`content.js` のセレクタ更新が必要になる可能性があります
